## How each top page is built

### Pattern A — SEO content machine (Copy.ai) — MOST TRAFFIC
- H1: Free Hook Generator
- Short benefit line
- Tool (embedded; page HTML is content-heavy)
- Long definition SEO body (“What is a Free Hook Generator?”)
- Benefits / AI explanation / step-by-step guide
- Who it’s for (3 personas)
- Huge related free-tools grid
- Product upsell (Workflows / Chat) after the free tool
- Thin on video-specific UX; thick on crawlable text + internal links

### Pattern B — Tool-first free utility (Summarizer, Poper, Fibr, Ahrefs)
- Hero H1 + tool widget above the fold (topic, tone, # of hooks, Generate)
- How to use (3–5 steps)
- Who can use / use cases
- FAQ
- Explore other tools grid
- Soft product CTA (Summarizer blogs; Poper popups; Fibr personalization; Ahrefs social suite)
- Summarizer leans essay/writing; Fibr adds platform dropdown (LinkedIn/IG/X/FB)

### Pattern C — Video SaaS converter (StoryCut) — BEST STRUCTURE FOR US, LOW TRAFFIC TODAY
- Exact H1: Viral Hook Generator
- Social proof under hero
- Clean tool card (topic + platform + tone)
- Product bridge (“turn words into viral videos”)
- Related tools cards
- Educational sections (why hooks matter, what makes a great hook)
- SEO FAQ
- Final purple CTA band
- Weak organic today (~5 ETV) because domain authority is tiny

### Pattern D — Hook asset library (Viralhooks, Meedro)
- Not a text generator; gallery of MP4 transitional/visual hooks
- Stats strip, live previews, download/affiliate
- Wins `viral hooks` / `transition hook` intent, not `hook generator`

### Pattern E — Ad creative tool (Motion)
- Generate + grade hooks from website URL
- Psychology framework cards (contrarian, curiosity gap, etc.)
- Heavy product upsell to creative analytics
- Ranks mid for hook generator with little SEO prose

## What SpyReels should copy (and not)

Copy from **traffic winners**:
1. Copy.ai’s depth: definition, steps, personas, related tools, long FAQ
2. Summarizer/Poper’s frictionless tool above the fold
3. Exact keyword H1 + internal tool cluster links

Copy from **StoryCut** (best short-form fit):
1. Platform + tone tool card
2. Why hooks matter / what makes a great hook cards
3. Product bridge to SpyReels (finder + full script), not caption editor
4. Social proof (only if real)

Do not chase StudyCorgi/essay SERP or Viralhooks MP4 library as the page model.

## Bottom line

1. **Most traffic on a hook landing page today: Copy.ai**, then Summarizer, then Ahrefs.  
2. **Best page architecture for SpyReels ICP: StoryCut**, but we must layer Copy.ai-level SEO depth so we actually get traffic.  
3. SpyReels currently has ~0 modeled organic on this cluster. Rebuild = StoryCut UX + Copy.ai SEO mass + SpyReels wedge.
